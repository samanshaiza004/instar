01 / WHY INSTAR

Idle means idle.

A suspended guest costs no periodic polls. The host wakes it for an event; independent async operations still make progress.

Open runtime notes ▸
02 / NATIVE BY DEFAULT

The window is not in Wasm.

Winit, layout, hit-testing, AccessKit, text shaping, CPU rendering, and presentation stay native and host-owned.
