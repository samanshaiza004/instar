Youth

A native host for untrusted, architecture-independent WebAssembly application components. Applications describe semantic retained UI through a typed WIT contract; the host owns rendering, input, durable state, and the transaction boundary around every guest turn.

Documentation GitHub

Try it

cargo install youth-cli --git https://github.com/samanshaiza004/youth
youth doctor
youth new tally
cd tally && youth dev

The project name derives the stable app ID dev.youth.tally; add --id when you need a different identity. The ID selects durable state and is not a display name.
Requires a Rust toolchain with the wasm32-wasip2 target; youth doctor checks and tells you what's missing. A packaged installer (curl | sh, no Rust toolchain to build the CLI itself) is planned for the first tagged release.
