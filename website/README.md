# instar.samanshaiza.com

This directory contains Instar’s static website. The landing page and stable
installer entry point live in `public/`; the task-oriented user guide lives in
`../docs/book/` and is built with mdBook. `build.sh` combines both into
`website/dist/` for Netlify.

## Build locally

```sh
bash website/build.sh
python3 -m http.server --directory website/dist 8000
```

Open `http://localhost:8000/` and `http://localhost:8000/docs/`.

The build pins mdBook 0.5.4. If it is absent, the script downloads the Linux
binary used by Netlify; local macOS/Windows development should install mdBook
through Cargo or a package manager first.

## Layout

- `public/index.html` — portal-style landing page.
- `public/assets/` — shared CSS, JavaScript, and original raster artwork.
- `public/install.sh` — stable macOS/Linux URL that delegates to the installer
  generated by the latest cargo-dist release.
- `../docs/book/` — searchable new-user and developer documentation.
- `../netlify.toml` — build, redirects, content types, and security headers.

## Deploy

Connect this repository to Netlify with `website/` as the base directory,
`bash build.sh` as the command, and `dist/` as the publish directory. Add
`instar.samanshaiza.com` as the production domain, then verify `/`, `/docs/`,
`/install`, and `/install.sh`.

No user-facing page should refer to the predecessor brand or repository. Old
names may remain in engineering archaeology and measured baseline documents
where changing them would falsify history.
