# Youth — Master Reference

The latest frozen application protocol is `youth:app@0.0.9`. It adds a `grow`
field to the wire node record for a forthcoming responsive-layout capability;
host layout behavior remains outside this protocol-only step. Protocols
`0.0.2` through `0.0.9` remain simultaneously supported.

Authoritative documents, in order of precedence:

1. [SCRATCHPAD-GATE-B.md](SCRATCHPAD-GATE-B.md) — implemented single real
   text-document capability and post-commit Save effect (`youth:app@0.0.8`);
   cross-platform release certification is pending.
2. [MILESTONE-2.md](MILESTONE-2.md) — completed Editor capability
   (host-owned text sessions, `youth:editor@0.0.1`, application protocol
   `0.0.6`) and modifier-aware shortcuts (application protocol `0.0.7`).
3. [DEVELOPER-PREVIEW-3.md](DEVELOPER-PREVIEW-3.md) — completed latest Utility
   Suite Todo milestone for bounded dynamic collections on application protocol
   `0.0.5`; its release tag is `utility-todo-gate-d-release`.
4. [DEVELOPER-PREVIEW-2.md](DEVELOPER-PREVIEW-2.md) — completed durable
   scheduling, countdown presentation, and recovery milestone:
   `youth:time@0.0.1` and application protocols `0.0.4`/`0.0.5`.
5. [DEVELOPER-PREVIEW-1.md](DEVELOPER-PREVIEW-1.md) — completed Utility Suite
   calculator milestone and application protocol `0.0.3`.
6. [DEVELOPER-PREVIEW-0.md](DEVELOPER-PREVIEW-0.md) — completed external
   application workflow at protocol `0.0.2`.
7. [MILESTONE-1.md](MILESTONE-1.md) — completed Transactional Visible Counter
   specification (application protocol `0.0.2`).
8. [MILESTONE-0.md](MILESTONE-0.md) — completed Headless Protocol Core
   specification (protocol version `0.0.1`).
9. [GUEST-PROFILE.md](GUEST-PROFILE.md) — Youth Rust Guest Profile 0.0.3:
   the guest import budget and build-target gating policy.

[DEVELOPER-PREVIEW-FINDINGS.md](DEVELOPER-PREVIEW-FINDINGS.md) is a durable
evidence log, not an authoritative specification.
[UTILITY-SUITE-FINDINGS.md](UTILITY-SUITE-FINDINGS.md) indexes evidence from
standalone Utility Suite application repositories.

Later capabilities, effects, and packaging milestones will be added here
as they are specified. Nothing in the codebase may prepare for them through
speculative abstractions.
