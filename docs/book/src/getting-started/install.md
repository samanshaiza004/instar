# Install Instar

## macOS and Linux

```sh
curl --proto '=https' --tlsv1.2 -fsSL \
  https://instar.samanshaiza.com/install | sh
```

The website script delegates to the installer generated by the latest GitHub
release. That installer detects the host architecture, downloads the matching
archive, verifies the release archive, and installs `instar` in
`${CARGO_HOME:-$HOME/.cargo}/bin`.

Make sure that directory is on `PATH`, then check the command:

```sh
instar --help
instar run --help
```

## Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -c `
  "irm https://github.com/samanshaiza004/instar/releases/latest/download/instar-shell-installer.ps1 | iex"
```

The PowerShell installer places `instar.exe` in Cargo’s bin directory.

## Before the first tagged release

If the installer reports that no Instar release exists yet, build from source:

```sh
git clone https://github.com/samanshaiza004/instar.git
cd instar
cargo install --locked --path crates/instar-shell
```

This is an honest fallback, not a separate distribution channel. The packaged
installer becomes the recommended path when the first release is published.

## Choose another install directory

Cargo-dist honors `CARGO_HOME`. For an isolated installation:

```sh
curl --proto '=https' --tlsv1.2 -fsSL \
  https://instar.samanshaiza.com/install | \
  CARGO_HOME="$HOME/.local/instar" sh
```

Add `$HOME/.local/instar/bin` to `PATH` before invoking `instar`.

## Uninstall

Remove the executable from the Cargo bin directory:

```sh
rm -f "${CARGO_HOME:-$HOME/.cargo}/bin/instar"
```

On Windows, remove `%CARGO_HOME%\bin\instar.exe` or the equivalent default
Cargo home path. See [Distribution](../reference/distribution.md) for receipts,
checksums, and release targets.
